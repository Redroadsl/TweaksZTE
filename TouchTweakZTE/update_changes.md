# 更新内容 - TouchTweakZTE

*新版本: Swift 3 WebUI*

*更新日期：20260613.* 

- 添加了WebUI！现在你可以方便地改变设置了；
- 自定义设置由ksu的模块配置存储，更新模块不会丢失；

- boot-completed.sh：每次开机读取自定义设置并应用；
- 删除action.sh，它的使命结束了。
- 其他优化改进。
